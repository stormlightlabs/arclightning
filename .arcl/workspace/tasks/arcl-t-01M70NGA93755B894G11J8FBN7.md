Reorganize the website documentation into the four Diátaxis types, each with
its own section and URL prefix, and rewrite every page to the writing-docs
standard. "Write the documentation content" left task guides that mixed
steps, explanation and reference on one page.

Acceptance criteria:

- [ ] The docs have four sidebar sections, Tutorials, How-to guides,
      Explanation and Reference, served under `/tutorials/`, `/how-to/`,
      `/explanation/` and `/reference/`. No page mixes steps with
      explanation
- [ ] Tutorials hold the quick start and a "plan and finish a feature with an
      agent" tutorial whose commands and output come from real runs
- [ ] Every page has a title and a description, and its commands, flags and
      output match a fresh `arcl` build and its `--help`
- [ ] Every old `/guides/…` URL, `/overview/` and `/quick-start/`, with
      their `.md` variants, redirect to an existing page with no chains, and
      keep the `#fragment`. The manual and automation anchors the old tests
      required still resolve at their new homes
- [ ] The header, landing page, footer, sitemap, `llms.txt`, search index,
      README and repository links point at the new pages, and the unit and
      e2e tests cover the new structure, including one that every old
      `/guides/` URL redirects to an existing page
